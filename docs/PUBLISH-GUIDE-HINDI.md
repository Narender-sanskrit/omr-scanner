# OMR स्कैनर — GitHub पर पब्लिश करने की पूरी गाइड

*शुरुआत से अंत तक, हर कदम पर। किसी कोडिंग की ज़रूरत नहीं है।*

> आपको चाहिए: एक कंप्यूटर (Windows या Mac), omr-scanner.zip फ़ाइल, एक ईमेल एड्रेस, इंटरनेट, और लगभग 20 मिनट।
>
> यह काम फ़ोन से भी हो सकता है, लेकिन फ़ाइलें अपलोड करना कंप्यूटर पर ज़्यादा आसान है।
>
> हम GitHub की वेबसाइट का इस्तेमाल करेंगे। आपको कुछ भी इंस्टॉल नहीं करना है, कोई कमांड नहीं चलानी है।
>

## स्टेप 1 — GitHub अकाउंट बनाएँ

1. ब्राउज़र में github.com खोलें।
2. ऊपर दाईं तरफ़ "Sign up" पर टैप करें।
3. अपना ईमेल डालें, पासवर्ड बनाएँ, और एक यूज़रनेम चुनें। इंग्लिश कैरेक्टर्स, बिना स्पेस — जैसे narender-semwal. यही यूज़रनेम आगे आपके लिंक में आएगा।
4. "Create account" पर क्लिक करें।
5. GitHub आपके ईमेल पर 8 अंकों का कोड भेजेगा। वह कोड डालें।
6. फिर पूछेगा कि कितने लोग इसे इस्तेमाल करेंगे — "Just me" चुनें।
7. प्लान चुनने को कहेगा — "Free" चुनें। पैसे नहीं लगेंगे, कार्ड की ज़रूरत नहीं है।
8. आखिर में "Continue" या "Skip personalization" पर क्लिक करके आगे बढ़ें।

## स्टेप 2 — नई repository बनाएँ

repository का मतलब है GitHub पर आपका प्रोजेक्ट फ़ोल्डर।

1. ऊपर दाईं तरफ़ "+" के निशान पर टैप करें, फिर "New repository" चुनें।
2. "Repository name" में लिखें: omr-scanner (छोटे अक्षर, बिना स्पेस, हाइफ़न ठीक है)।
3. "Description" में कुछ भी लिख सकते हैं, जैसे OMR answer sheet scanner.
4. नीचे "Public" चुनें, Private नहीं — फ़्री प्लान पर Pages सिर्फ़ public में चलता है।
5. "Add a README file" वाले बॉक्स पर टिक न करें — README हमारी ज़िप में पहले से है।
6. "Create repository" पर क्लिक करें।
7. अब एक पेज खुलेगा जिस पर "Quick setup" लिखा होगा। इसे बंद न करें, आगे काम आएगा।

## स्टेप 3 — फ़ाइलें अपलोड करें

1. कंप्यूटर पर omr-scanner.zip को अनज़िप करें। इससे एक फ़ोल्डर बनेगा जिसमें index.html, app.js, omr-engine.js, samples, tools, आदि होंगे।
2. ज़रूरी बात: फ़ोल्डर के अंदर की चीज़ें अपलोड करनी हैं, फ़ोल्डर को नहीं। GitHub पर index.html सीधे दिखना चाहिए, omr-scanner/index.html नहीं।
3. रिपॉज़िटरी पेज पर "uploading an existing file" लिंक पर टैप करें।
4. अब सभी फ़ाइलों और फ़ोल्डरों को एक साथ चुनकर बॉक्स में ड्रैग करें। फ़ोल्डर भी ड्रैग हो जाते हैं — samples, tools, assets, docs, templates, सब।
5. अपलोड पूरा होने का इंतज़ार करें। आपको लगभग 50 फ़ाइलें दिखेंगी।
6. हरे बटन के ऊपर वाले बॉक्स में लिखें: first upload
7. "Commit changes" पर क्लिक करें।

## स्टेप 4 — GitHub Pages चालू करें

यही स्टेप आपके प्रोजेक्ट को एक असली वेबसाइट का पता देता है।

1. रिपॉज़िटरी के अंदर ऊपर "Settings" टैब पर टैप करें।
2. बाईं ओर की लिस्ट में नीचे "Pages" पर टैप करें।
3. "Source" में "Deploy from a branch" चुनें।
4. "Branch" में main चुनें, और फ़ोल्डर को "/ (root)" ही रहने दें।
5. "Save" पर क्लिक करें।
6. एक-दो मिनट रुकें, फिर पेज को रिफ़्रेश करें।
7. ऊपर एक हरा मैसेज दिखेगा: "Your site is live at https://your-username.github.io/omr-scanner/"
8. उस लिंक को कॉपी कर लें। यही आपका ऐप है।

## स्टेप 5 — फोन पर ऐप की तरह इंस्टॉल करें

**Android फोन पर (Chrome):**

1. कॉपी किए गए लिंक को Chrome में खोलें।
2. ऊपर दाईं ओर तीन बिंदुओं (three dots) पर टैप करें।
3. "Install app" या "Add to Home screen" चुनें।
4. "Install" दबाएं।
5. होम स्क्रीन पर OMR Scanner का आइकन आ जाएगा।
6. ऐप के अंदर भी Setup टैब पर एक "Install app" बटन है — वहां से भी हो जाएगा।

**iPhone पर (Safari):**

1. लिंक को Safari में खोलें, Chrome में नहीं — iPhone पर सिर्फ Safari ही यह काम करता है।
2. नीचे बीच में Share आइकन पर टैप करें, जो ऊपर की ओर तीर वाला चौकोर है।
3. मेनू में नीचे स्क्रॉल करें और "Add to Home Screen" चुनें।
4. ऊपर दाईं ओर "Add" दबाएं।
5. होम स्क्रीन पर आइकन आ जाएगा।

## स्टेप 6 — पहली बार का इस्तेमाल

1. होम स्क्रीन के आइकन पर टैप करें। ऐप पूरी स्क्रीन में खुलेगा, ऊपर कोई address bar नहीं होगा।
2. "Sheet template" टैब खोलें और "Download printable PDF" दबाएं।
3. उस PDF को A4 पेपर पर 100% साइज़ पर प्रिंट करें। "Fit to page" न चुनें, वरना चारों कोने के काले चौकोर खिसक जाएंगे।
4. "Setup" टैब में जाकर answer key भरें — एक लाइन में ABCDABCD... टाइप कर दें।
5. roster CSV अपलोड करें (roll,name,class,section)।
6. "Scan" टैब में जाकर "Start camera" दबाएं और शीट की फोटो लें।

## आगे कोई बदलाव करना हो तो

1. अगर आपको कोई बदलाव करना है, तो GitHub पर अपनी repository में जाएं।
2. "Add file" पर क्लिक करें और फिर "Upload files" पर क्लिक करें।
3. जिस फ़ाइल को आप बदलना चाहते हैं उसे अपलोड करें, वह पुरानी फ़ाइल के ऊपर ही लिख दी जाएगी।
4. "Commit changes" पर क्लिक करें।
5. एक मिनट बाद, अपने फ़ोन पर ऐप को बंद करके दोबारा खोलें — नया वर्ज़न आ जाएगा।

## अगर कुछ गड़बड़ हो जाए

**क्या कैमरा नहीं खुल रहा?**

लिंक https वाला होना चाहिए, यानी github.io. फ़ोन में सेव की गई HTML फ़ाइल से कैमरा नहीं चलता।

**क्या 404 दिख रहा है?**

Pages सेव करने के बाद 2-3 मिनट लगते हैं। Settings में Pages खोलकर देखें कि हरा मैसेज आ गया है या नहीं। यह भी चेक करें कि index.html repository के रूट में है।

**क्या Install बटन नहीं दिख रहा?**

ब्राउज़र के मेन्यू से "Add to Home screen" कर लें। iPhone पर यह बटन कभी नहीं दिखता, वहां सिर्फ Share वाला तरीका ही काम करता है।

**क्या पुराना वर्ज़न दिख रहा है?**

ऐप को बंद करके दोबारा खोलें। अगर फिर भी ठीक न हो, तो Chrome की settings से उस साइट का डेटा क्लियर कर दें।

## आगे चलकर, अगर मन हो (ज़रूरी नहीं)

अगर आप कभी कमांड लाइन सीखना चाहें, तो git इंस्टॉल करने के बाद सिर्फ चार कमांड काफी हैं: git clone, git add ., git commit -m "update", git push. अभी के लिए वेबसाइट वाला तरीका पूरी तरह से काफी है।
